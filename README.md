# Chrome Hearts

An interactive front-end web application inspired by the iconic aesthetic and design philosophy of Chrome Hearts. Built with HTML5, modern CSS layouts, and vanilla JavaScript.

## Overview

This project is a visual showcase and product gallery created out of a personal appreciation for Chrome Hearts' distinct bold typography, streetwear aesthetic, and luxury leather and silver craft. It features a modern desktop layout, responsive media adjustments, and dynamic front-end filtering.

## Key Features

* **Live Search Filter:** Uses dynamic JavaScript event listeners (`keyup`) to instantly filter product cards in real time based on user input.
* **Interactive Product Modal:** Clicking any product card opens an overlay modal pop-up displaying an enlarged product image, detailed title, and description.
* **Custom Typography:** Integrated custom font styling (`CloisterBlack.ttf`) to match the signature gothic aesthetic of the brand.
* **Responsive Layouts:** Structured using CSS Grid and Flexbox for screen adaptation across mobile and desktop breakpoints.

## Built With

* **HTML5** – Page markup, modal structures, and semantic sections
* **CSS3** – Custom layout, CSS Grid, Flexbox, media queries (`@media`), and hover animations.
* **JavaScript** – DOM manipulation, real-time search filtering, and event-driven modal popups.
